## 1. Process

1. Separate brand design from print-piece theme. Decide how the brand's impression is expressed in this environment (A, B).
2. Decide the core idea by the protocol (C).
3. Decide the style direction by the protocol (D).
4. Decide the hero, or its deliberate absence, by the protocol (E).
5. Resolve the Phase 2 tensions deliberately; set governing principles, including space intent and mark role (F).
6. Run the stress tests (G).
7. Record candidates, strengths, weaknesses, the decisive criterion, and rejected directions; pass the gate.

The three protocol decisions are sequential: the winning core idea becomes a criterion for style; the winning style becomes a criterion for the hero. Do not generate style candidates before the core idea is chosen. Run an image-model renderability check on each candidate's visual behavior (the prompt specialist's standing duty in Phases 3 to 5). For several concepts, the protocol runs once to rank core idea candidates; each concept then takes a different structurally distinct candidate (each still passing the five properties), and style and hero run the full protocol per concept.

## 2. Detailed guidance

### A. Brand design
How identity, personality, values, positioning, and core message are expressed visually: the enduring identity that stays recognizable across formats. For an established brand it is mostly discovered and respected (fixed assets bind it). For a new brand it is proposed with restraint proportional to the evidence. State it separately so that the theme can vary without damaging it.

### B. Print-piece theme
The creative concept for this piece, translating the brand into an idea suited to the medium, objectives, audience, content, and environment. Hold the brand's impression constant and let the Environment Profile decide how it is expressed here. If the theme contradicts the brand design, either the theme is wrong or the brand design needs a deliberate, approved evolution; resolve it rather than carry the contradiction forward.

### C. The core idea
A mood word or product category is not a core idea. A core idea relates something true about the business to something the audience recognizes, in a way that suggests a visual structure. Test each candidate on five properties: **specific** (belongs to this business), **visual** (suggests something seen), **generative** (theme, hero, style, and layout can follow from it), **truthful** (the business can honestly claim it), **functional** (it helps the piece do its job in its setting).

Source candidates differently: the Visual source inventory's deeper specifics; the Environment Profile's departure dimension; the weakest link; the differentiator; the name or origin. Name the apparent core idea first as the benchmark. Candidates differ on a structural axis (what carries the identity, what the viewer does first, how information is structured, register, image-making method), not on color or ornament.

### D. Style direction
Define across dimensions: visual language, artistic and historical influences, compositional behavior, material character, image-making technique, typographic expression, light and atmosphere. Use established, specific terminology whose meaning an illustrator could act on. Avoid generic labels and familiar combinations unless evaluated and justified. Creativity comes from synthesis of the brief's conditions, not arbitrary additions. A style direction fails if it is a list of mood adjectives. Test the winner for obviousness: would a stranger predict it from category and place alone?

### E. Main visual concept (hero)
Consider symbolic marks, objects, products, people, mascots, environments, illustrations, photography, abstract forms, typography-led concepts, and restraint with no hero. For each candidate decide: does it recognizably serve the viewing stage where it is needed; does it truthfully represent what is sold; does it support or compete with the mark; can an image model render it reliably. Where the hero is the product, the depiction matches what the business actually offers. Avoid real identifiable people, and avoid dependence on complex hands, crowds, or fine faces unless reliability allows. For a standalone logo request the mark is the hero by definition; the protocol still runs for the core idea and style, and the mark itself is developed in Phase 4.

### F. Governing principles
Settle each with a reason:
- **Character and tone;** commercial positioning;
- **Energy and rhythm; density;**
- **Dominant and supporting relationships;**
- **Boundaries:** what the design must never become;
- **Space intent.** The share of the format that must stay quiet, and what that space does (separate the glance content, give the eye rest, signal positioning). Derive it from format size, viewing distance, content volume, and positioning. Larger media raise the space intent or the strength of the main idea; they do not raise the number of elements. This is the first place restraint is set, before elements exist;
- **Mark role:** whether the mark leads the hierarchy, anchors it, or signs off, chosen against the Communication Problem and the hero. The role fixes how much weight Phase 4 and 5 give the identifier.

Resolve each Phase 2 tension by stating which side leads and what the other side is allowed to keep.

### G. Stress tests
Run all seven and record the result of each:
1. **Swap test.** Substitute a competitor; if the plan still works unchanged, it is generic.
2. **Category test.** Remove the product; if the identity could belong to the industry, it is stereotyped.
3. **Apparent-choice test.** Would a stranger predict the hero and style from category and place alone?
4. **Context-swap test.** Would the plan be equally right in another setting? If so, it ignores the environment.
5. **Distance and attention test.** Does the first impression hold in the real setting at the glance stage?
6. **Contradiction scan.** Do brand design, theme, core idea, style, hero, and governing principles agree?
7. **Ambition check.** Against content, budget, and format.

A failure routes back to the decision that caused it within this phase; cap at two revision cycles per issue.

## 3. Failure modes

| Failure | Detection | Correction |
|---|---|---|
| Mood-word core idea | The idea cannot generate a hero or layout | Re-source from the inventory or the weakest link |
| Apparent option wins by default | No decisive criterion, or "it is fitting" as the reason | Name the criterion on which less obvious candidates fell short, or choose among them |
| Candidates differ only in decoration | No structural axis distinguishes them | Rewrite candidates on a structural axis |
| Style as adjective list | An illustrator could not act on it | Re-state across the seven style dimensions |
| Style stack by assignment | A different style assigned to each insight | Synthesize one style from all findings |
| Environment-blind plan | Passes the context-swap test unchanged | Re-derive with the departure dimension as a source |
| Hero that misrepresents | The hero is not what is sold | Replace or restrain |
| Space intent missing or vague | No share, no job | Derive from format, distance, volume, positioning |
| Compromise instead of hybrid | The chosen idea needs "and also" | Choose one logic and drop or subordinate the rest |
| Brand design and theme collapse | The theme alters the enduring identity without approval | Separate them again; restore the identity |

## 4. Completion criteria, summary record, and hand-off

Complete when the phase card's "Before leaving" check holds.

**Record for the decision summary (Design Plan block):** for the core idea, style, and hero, each: the apparent option, the candidates compared (one line each: name, key strength, key weakness), the choice with a one-sentence rationale including why it beat the runner-up and what was combined or repaired. Mark any decision fixed by the user or evidence as such. Update the Design Log: core idea, style, hero, space intent, mark role, open issues.

**Hand-off to Phase 4:** the Design Plan (core idea, style, hero, governing principles including space intent and mark role), the rejected directions, plus the Environment Profile, Visual source inventory, and Phase 1's content, fixed assets, and constraints.
