## 1. Process

1. Inventory fixed assets and production constraints.
2. Decide the color strategy by the protocol (A) and the typographic voice by the protocol (B), both as provisional constraints for the mark.
3. Develop the logo mark through the extended development (C). If the mark reveals a conflict with color or type, return within the phase and adjust those decisions.
4. Run the deficit analysis and select visual supporters (D).
5. Decide background and unifying devices (E) and any additional systems (F).
6. Evaluate the system as a whole: element allowance check against the space intent, interaction check, removal test, consistency of rendering treatment, subtraction pass (G).
7. Record candidates and choices; pass the gate.

## 2. Detailed guidance

### A. Color system
Decide the logic first (what color is doing in this piece), then roles (dominant, supporting, accent where relevant). Monochrome, dual-tone, restrained multicolor, and complex systems are all valid when justified. Decide: contrast structure; relationship to imagery; brand continuity (existing colors are fixed assets); cultural and category associations (verify them); reproduction under the user's production limits.

Judge the palette against the surrounding color field and ambient light, and decide whether it departs from or sits within the landscape and on which dimension, as set by the Environment Profile. Describe colors to a model by named hues with qualifiers and roles; use hex values only for supplied brand colors or where precision is essential.

### B. Typography
Define roles (display, supporting, informational, numerals and prices, small print), character, relationships, readability at the real distance and light, and integration with the hero and the mark. Judge the voice against the lettering of the surroundings. Keep roles few. Set sizes as ratios between roles that follow reading stages, not as independent sizes. Describe type to a model by characteristics, because font names are unreliable; use a name only for a stated brand requirement. Dense text raises rendering risk; plan structure accordingly (grouping, rows, fewer styles).

### C. The logo mark (a critical decision; the longest deliberation in this phase)

A basic, generic, or forgettable mark is a failure even if it passes every test. If the mark was settled quickly, it was not scrutinized.

**Hard rules.**
- **A new identifier is never only a styled name.** Every identifier the skill creates carries a personality device. The device may be formed by transforming part of the lettering, integrating a symbol with the name, a distinctive silhouette or container, a symbol beside the name, or a combination. It is never decoration added to look designed.
- **Fixed assets are respected.** A user-supplied logo, including a plain wordmark, is used as given and is not redesigned, restyled, simplified, or recolored unless the user asks. The personality-device rule applies to marks the skill creates. If the user explicitly asks for plain text, the explicit request governs. With a fixed logo, the decisions that remain are its role, region, clear space, and relation to the rest of the system; record that the mark development was not required because the identifier is fixed.

**Extended development (do not collapse into one pass).**
1. **Concept mining.** Write at least six raw concept seeds from different sources: the name's meaning, sound, or shape; the product's defining truth; process or craft; origin; the customer's ritual; the Visual source inventory; the Environment Profile; a visual signature of the business. Include seeds beyond the apparent. Mark each as true, ownable, and visually workable, or discard it. Discard any seed the business cannot honestly claim.
2. **Three developed candidates.** Each is a complete mark idea: seed, personality device, relation to the lettering, construction family, and behavior at small size. Candidates differ in concept source or construction; at most one is the apparent option. Weigh these construction families as genuine alternatives, without defaulting to one structure across businesses: **enclosed** (symbol held within a boundary), **contained** (elements held together by a frame or shape), **integrated** (symbol fused with lettering), **emblematic** (a unified crest-like arrangement), **open** (a freestanding symbol with no boundary).
3. **Scrutiny of each candidate** (eight questions):
   - *Generic:* if the name were swapped for a competitor's, would it still work?
   - *Story:* what true thing does it say, and can the business claim it?
   - *Memory:* can it be described in one sentence and redrawn from memory?
   - *Silhouette:* is it recognizable in a single solid color?
   - *Device necessity:* without the device, does it fall back to a styled name?
   - *Cliché:* is it the first association?
   - *Lockup:* do mark and wordmark share a logic without blending?
   - *Renderability:* can an image model reproduce its geometry from a description?
4. **Revision pass.** At least one genuine revision after critique: transplant a strength, sharpen the idea, remove excess, ask what would make it more ownable while still true. Then choose by the exploration protocol (SKILL.md section 7), including the runner-up comparison and the decisive criterion.
5. **Tests** (five): *isolation* (the mark alone, with nothing near it); *reduction* (one color, small); *separation* (from hero, lettering, and decoration); *text-neighborhood* (beside the densest text, squinting); *memory* (describe it, then redraw it from the description). If the winner still feels basic, return to concept mining with the weakness named.
6. **Preparation for generation.** Image models render simple, geometric, clearly described marks far more reliably than intricate ones. Simplify the execution of the idea, never the idea itself into something generic. Define geometry, key shapes, relationships, and color concretely.

**Distinction from typography and content.** A mark reads as more type when it belongs to the same form class as the text around it, most severely in text-heavy layouts. Judge distinction as a relationship in the composition. Use the six distinction mechanisms as the composition requires, usually two or more in dense layouts:
1. **Form class:** a silhouette of shapes and masses. Where a device is formed from lettering, the transformed part reads as a shape first and a letter second.
2. **Mass and texture:** compact solid weight against the even linear texture of text.
3. **Color role:** a color or field the mark holds and body text does not share.
4. **Scale step:** a deliberate size step sized to the mark's role, not enlargement to compensate for weak distinction.
5. **Isolation:** protected clear space that no text, ornament, or pattern enters.
6. **Containment or anchoring:** a container, field, or fixed anchor region with a stable edge and position, repeated consistently across faces.

Define the relationship with the wordmark: shared logic of proportion, weight, and geometry, but not the same form class; the mark must work when separated. In dense layouts, resolve distinction by composition (its own region, neighboring type not echoing its form), never by endless enlargement. The mark's weight follows the mark role set in Phase 3.

### D. Visual supporters
Start with a **deficit analysis:** what would be missing if the piece consisted only of its required text. Add supporters only to address real deficits, across the full range of functions: primary attention and storytelling; product or service representation; brand identity reinforcement; emotional and atmospheric communication; information comprehension and categorization; supporting illustration and iconography; decorative refinement and compositional balance; connection between content groups.

For each supporter record role, relevance, treatment, scale, placement, relationship. Supporters sit below the hero, mark, and primary message in the hierarchy and are limited by the element allowance; remove a supporter that must be shrunk to fit or that crowds a glance-stage element. Draw motifs and illustrations from the Visual source inventory; treat the category's or culture's obvious decorative signifiers as the benchmark to beat. Product depictions match what the business actually offers. Avoid real identifiable people, tokenistic portrayals, and compositions that depend on complex hands, crowds, or fine faces unless reliability allows. Micro-details demonstrate craft and are few; accumulation is noise.

### E. Background and unifying devices
Decide color, texture, imagery, tonal structure, spatial structure, and the relationship to the foreground; and whether connecting devices are needed to unify zones. The background also separates the piece from its landscape, so judge it against the neighbors and light. It stays quiet where information lives.

### F. Additional design systems
Graphic shapes, framing, borders, patterns, textures, material effects, lighting, shadows, image treatments, iconography, information graphics, spatial transitions. Include only what improves the design. Lighting and shadow are decisions, not inherited defaults; state their direction and softness or leave them out.

### G. Element-level evaluation
- **Real alternatives** for identity-defining elements (color, type, mark, any open hero treatment).
- **Element allowance check.** Every element has a space cost. Sum the costs against the Phase 3 space intent. If the total exceeds it, remove or merge elements before any is shrunk.
- **Interaction check** for each pair of major elements (mark and type, hero and background, color and imagery).
- **Removal test** for every element: if removing it changes nothing the piece needs, remove it.
- **Cumulative effect:** does the whole read as one designer's work?
- **Consistency:** line quality, finish, level of abstraction, light direction, rendering treatment.
- **Subtraction pass:** remove one more thing and see whether the piece improves.

System-wide coherence outranks isolated appeal.

## 3. Failure modes

| Failure | Detection | Correction |
|---|---|---|
| Styled name passed as identity | Without the device the identifier is plain lettering | Return to concept mining; require a personality device |
| Mark settled in one pass | No seeds, no three candidates, no revision, no tests recorded | Run the extended development |
| Cliché mark | The mark is the first association of the category or culture | Re-mine beyond the apparent; apply the decisive criterion honestly |
| Mark absorbed by type | Fails the text-neighborhood test | Add distinction mechanisms by composition (not enlargement); change form class |
| Mark too intricate for a model | Geometry cannot be described in a few concrete shapes | Simplify execution, keep the idea |
| Supplied logo touched | Any redesign, restyle, simplification, or recoloring | Restore as given |
| Decoration without a deficit | A supporter with no deficit it answers | Remove it |
| Space cost ignored | Total elements exceed the space intent | Remove or merge elements before shrinking any |
| Palette judged only against the brand | No reference to the surrounding color field or light | Re-judge against the Environment Profile |
| Font names used as direction | Font names without a stated brand requirement | Replace with characteristics |
| Inconsistent rendering | Mixed line quality, finish, or light direction | Unify treatment across elements |
| Default lighting and shadow | Shadow or glow no decision explains | Decide or remove |
| First-candidate color or type | No recorded alternatives | Run the protocol |

## 4. Completion criteria, summary record, and hand-off

Complete when the phase card's "Before leaving" check holds.

**Record for the decision summary (Design Elements block):** color strategy (apparent option, candidates, choice, rationale); typographic voice (same); the mark: the truth it expresses, the personality device, the construction family chosen against the other candidates, the runner-up, the distinction mechanisms used (or "fixed asset"). Update the Design Log: color, type, mark, element costs, open issues.

**Hand-off to Phase 5:** the element system with every element's role, treatment, relationships, and space cost; the mark with its mechanisms; the constraints that the prompt must preserve.
