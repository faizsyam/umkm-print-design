# Phase 4: Design Elements

## Phase card

## 1. Process

1. Inventory fixed assets and production constraints.
2. Decide the color strategy (A) and the typographic voice (B) by the protocol, as provisional constraints for the mark. Both must realize the Phase 3 style dimensions (chromatic stance; typographic expression).
3. Develop the mark and lockup through the extended development (C). If it reveals a conflict with color or type, return within the phase and adjust those decisions.
4. Run the deficit analysis and select visual supporters (D).
5. Decide background and unifying devices (E) and any additional systems (F).
6. Evaluate the system as a whole (G): effect profiles, interactions, realization trace, element allowance check, removal and subtraction passes.
7. Record candidates and choices; pass the gate; print the entry.

## 2. Detailed guidance

### A. Color system

**Analyze**
- The Phase 3 chromatic stance and the light and atmosphere it sets.
- Fixed brand colors (fixed assets) and production limits (ink count, substrate, finish).
- The surrounding color field and ambient light from the Environment Profile.

**Candidate card fields (color strategy)**
1. The logic: what color is doing in this piece (organize, signal, separate, evoke, depart from the landscape).
2. Roles: dominant, supporting, accent where relevant; how many hues and the area proportion of each.
3. Harmony structure, value structure, chroma, and temperature.
4. Contrast structure for each reading stage.
5. Relationship to imagery and to the mark.
6. Behavior under the production limits and in the real light.
7. Cultural and category associations (verified).

**Evaluate**
- Monochrome, dual-tone, restrained multicolor, and complex systems are all valid when justified.
- Whether the palette departs from or sits within the landscape, and on which dimension.
- The context matrix, interaction with the style and hero, and the originality tests.
- Describe colors to a model by named hues with qualifiers and roles; use hex values only for supplied brand colors or where precision is essential.

### B. Typography

**Analyze**
- The Phase 3 typographic expression.
- The roles the content needs: display, supporting, informational, numerals and prices, small print.
- The lettering of the surroundings.

**Candidate card fields (typographic voice)**
1. Classification and stance for each role.
2. Construction traits: stroke contrast, proportion, x-height, widths, terminals, spacing and line-spacing character.
3. Relationships between roles (pairing logic) and size ratios that follow reading stages.
4. Treatment of numerals and prices.
5. Readability at the real distance and light.
6. How the wordmark's lettering relates to, and differs from, the informational type (see C, unit distinction).
7. Rendering risk for an image model.

**Evaluate**
- Keep roles few.
- Set sizes as ratios between roles, not as independent sizes.
- Dense text raises rendering risk; plan structure accordingly (grouping, rows, fewer styles).
- Describe type to a model by characteristics, because font names are unreliable; use a name only for a stated brand requirement.
- The context matrix and interaction with the mark and hero.

### C. The identity unit: logo mark, wordmark, and lockup

A basic, generic, or forgettable identifier is a failure even if it passes every test. If it was settled quickly, it was not scrutinized.

**Hard rules**
- **A new identifier is never only a styled name.** Every identifier the skill creates carries a personality device: formed by transforming part of the lettering, integrating a symbol with the name, a distinctive silhouette or container, a symbol beside the name, or a combination. Never decoration added to look designed.
- **Fixed assets are respected.** A supplied logo, including a plain wordmark, is used as given: not redesigned, restyled, simplified, or recolored unless the user asks. If the user explicitly asks for plain text, that governs. With a supplied lockup, record that mark development was not required; the remaining decisions are its role, region, clear space, and relation to the system. With a supplied mark and a separately supplied name, leave both assets unaltered and decide only arrangement, spacing, alignment, and color roles.

**Extended development** (do not collapse into one pass)
1. **Concept mining.** Write at least six raw concept seeds from different sources: the name's meaning, sound, or shape; the product's defining truth; process or craft; origin; the customer's ritual; the Visual source inventory and the Phase 3 survey; the Environment Profile; a visual signature of the business. Include seeds beyond the apparent. Mark each as true, ownable, and visually workable, or discard it. Discard any seed the business cannot honestly claim.
2. **Three developed candidates.** Each candidate card is a complete identity unit idea:
   - seed and personality device;
   - construction family;
   - the lockup (arrangement, proportion, shared construction logic, see below);
   - behavior at small size.

   Candidates differ in concept source or construction; at most one is the apparent option. Weigh these construction families as genuine alternatives: **enclosed** (symbol held within a boundary), **contained** (elements held together by a frame or shape), **integrated** (symbol fused with lettering), **emblematic** (a unified crest-like arrangement), **open** (a freestanding symbol with no boundary).
3. **Scrutiny of each candidate** (eight questions):
   - *Generic:* if the name were swapped for a competitor's, would it still work?
   - *Story:* what true thing does it say, and can the business claim it?
   - *Memory:* can it be described in one sentence and redrawn from memory?
   - *Silhouette:* is it recognizable in a single solid color?
   - *Device necessity:* without the device, does it fall back to a styled name?
   - *Cliché:* is it the first association?
   - *Lockup:* do mark and wordmark read as one object while each keeps its own form?
   - *Renderability:* can an image model reproduce its geometry from a description?
4. **Revision pass.** At least one genuine revision after critique: transplant a strength, sharpen the idea, remove excess, ask what would make it more ownable while still true. Then choose by the protocol, including runner-up and decisive criterion.
5. **Tests** (five): *isolation*; *reduction* (one color, small); *separation* (from hero, lettering, and decoration); *text-neighborhood* (beside the densest text, squinting); *memory* (describe, then redraw). If the winner still feels basic, return to concept mining with the weakness named.
6. **Preparation for generation.** Image models render simple, geometric, clearly described forms far more reliably than intricate ones. Simplify the execution of the idea, never the idea itself into something generic. Define geometry, key shapes, relationships, and color concretely.

**Lockup integration** (mark and wordmark must form one cohesive unit, not two objects placed near each other). Decide each of the following explicitly:
- **Arrangement:** how the two combine (beside, stacked, held in one container, mark integrated into the lettering), weighed against the viewing stage and the format region the unit will occupy.
- **Shared construction logic:** a common module drawn from the mark (stroke weight, curvature, angle, proportion unit) that the wordmark lettering echoes, so they look drawn by one hand.
- **Spatial relationship:** spacing derived from a measurable unit of the mark, not arbitrary; a shared alignment axis (baseline, cap height, or center); optical balance of mass between mark and lettering.
- **Weight and scale relationship:** a fixed proportion between mark and wordmark; the unit scales as one.
- **Color logic:** one role scheme for the whole unit; mark and wordmark share a color family with defined roles.
- **Internal hierarchy:** which element leads inside the unit; the unit reads in a single glance as one object.
- **Separability:** the mark works alone; the wordmark alone still carries the same construction logic.
- **Form class:** mark and wordmark share logic but not form class (the mark reads as shape and mass first; the wordmark as lettering), so integration never becomes blending.

Tests: *unit test* (squint: does it read as one object?); *disconnection test* (cover the mark, then the wordmark: does each remain recognizably of the same identity?).

**Distinction of the identity unit from typography and content.** A mark reads as more type when it shares a form class with the text around it, most severely in text-heavy layouts. The wordmark is also not body type: it must be distinguishable from the informational typography in construction, weight, or treatment. Judge distinction as a relationship in the composition, applied to the **unit as a whole**. Use the six distinction mechanisms as the composition requires, usually two or more in dense layouts:
1. **Form class:** a silhouette of shapes and masses; a device formed from lettering reads as a shape first and a letter second.
2. **Mass and texture:** compact solid weight against the even linear texture of text.
3. **Color role:** a color or field the unit holds and body text does not share.
4. **Scale step:** a deliberate size step sized to the unit's role, not enlargement to compensate for weak distinction.
5. **Isolation:** protected clear space, measured from the unit, that no text, ornament, or pattern enters.
6. **Containment or anchoring:** a container, field, or fixed anchor region with a stable edge and position, repeated consistently across faces.

In dense layouts, resolve distinction by composition (the unit's own region, neighboring type not echoing its form), never by endless enlargement. The unit's weight follows the mark role set in Phase 3.

### D. Visual supporters

**Analyze: the deficit analysis**
- What would be missing if the piece consisted only of its required text?
- Across the full range of functions: primary attention and storytelling; product or service representation; brand identity reinforcement; emotional and atmospheric communication; information comprehension and categorization; supporting illustration and iconography; decorative refinement and compositional balance; connection between content groups.

**Consider** for each supporter
- Role, relevance, treatment, scale, placement, and relationship to the hero and identity unit.
- Source: draw motifs and illustrations from the Visual source inventory and the Phase 3 survey; treat the category's or culture's obvious decorative signifiers as the benchmark to beat.
- Accuracy: product depictions match what the business offers.
- Reliability: avoid real identifiable people, tokenistic portrayals, and compositions that depend on complex hands, crowds, or fine faces unless reliability allows.

**Evaluate**
- Add a supporter only to answer a real deficit.
- Supporters sit below the hero, identity unit, and primary message in the hierarchy and are limited by the element allowance; remove one that must be shrunk to fit or that crowds a glance-stage element.
- Micro-details demonstrate craft and are few; accumulation is noise.

### E. Background and unifying devices

**Analyze**
- Color, texture, imagery, tonal structure, spatial structure.

**Consider**
- The relationship to the foreground.
- Whether connecting devices are needed to unify zones.
- That the background separates the piece from its landscape; judge it against neighbors and light.

**Evaluate**
- It stays quiet where information lives.
- Its effect profile (G) on mark, hero, and text.

### F. Additional design systems

**Analyze**
- Graphic shapes, framing, borders, patterns, textures, material effects, lighting, shadows, image treatments, iconography, information graphics, spatial transitions.

**Evaluate**
- Include only what improves the design, each with a named job.
- Lighting and shadow are decisions, not inherited defaults: state direction and softness, or leave them out.

### G. Element selection and evaluation in the system

**Purpose.** Select each element for what it does to the whole design, and evaluate it in relation to the complete system, not in isolation.

**1. Effect profile (for every element).** State the element's effect on each of the following as supports, neutral, or strains, with one concrete line wherever it matters:
- brand design and positioning;
- the core idea and theme;
- the style dimensions;
- the piece's communication objective and weakest link;
- the audience encounter at each viewing stage;
- the environment (neighbors, light, distance; fit and departure);
- content capacity and space cost;
- production and renderability.

**2. Interaction check.** For each pair of major elements (identity unit and type, hero and background, color and imagery, supporters and hero), state whether they amplify, compete, or are neutral, and repair any competition.

**3. Realization trace** (SKILL.md 7.3 f). Each element names the plan commitment it realizes; an element that realizes none is removed; a plan commitment realized by no element is a gap to close.

**4. System-level checks**
- **Element allowance:** every element has a space cost; sum the costs against the Phase 3 space intent; if the total exceeds it, remove or merge elements before any is shrunk.
- **Removal test:** if removing the element changes nothing the piece needs, remove it.
- **Cumulative effect and single voice:** does the whole read as one designer's work?
- **Consistency:** line quality, finish, level of abstraction, light direction, rendering treatment.
- **Subtraction pass:** remove one more thing and see whether the piece improves.

System-wide coherence outranks isolated appeal.

## 3. Failure modes

| Failure | Detection | Correction |
|---|---|---|
| Styled name passed as identity | Without the device the identifier is plain lettering | Return to concept mining; require a personality device |
| Disconnected mark and wordmark | The unit and disconnection tests fail; spacing, alignment, or color logic is arbitrary | Redesign the lockup with a shared construction logic and derived spacing |
| Identity unit absorbed by type | Fails the text-neighborhood test; the wordmark echoes the body type | Add distinction mechanisms by composition; differentiate wordmark from informational type |
| Mark settled in one pass | No seeds, no three candidates, no revision, no tests | Run the extended development |
| Cliché mark | The mark is the first association | Re-mine beyond the apparent; apply the decisive criterion honestly |
| Mark too intricate for a model | Geometry cannot be described in a few concrete shapes | Simplify execution, keep the idea |
| Supplied logo touched | Any redesign, restyle, simplification, or recoloring | Restore as given |
| Element with no plan source | The realization trace finds no commitment it realizes | Remove it, or return to Phase 3 if the plan has a gap |
| Element judged in isolation | No effect profile or interaction check | Complete both |
| Decoration without a deficit | A supporter answering no deficit | Remove it |
| Space cost ignored | Total exceeds the space intent | Remove or merge elements before shrinking any |
| Palette judged only against the brand | No reference to the surrounding field, light, or the full parameter set | Re-judge against the Environment Profile and context matrix |
| Font names used as direction | Font names without a stated brand requirement | Replace with characteristics |
| Inconsistent rendering | Mixed line quality, finish, or light direction | Unify treatment |
| Default lighting and shadow | Shadow or glow no decision explains | Decide or remove |
| First-candidate color or type | No candidate cards or alternatives | Run the protocol |

## 4. Completion criteria, summary print, and hand-off

Complete when the phase card's "Before leaving" check holds.

**Print for the decision summary (Design Elements entry, at the gate):**
- color strategy and typographic voice: apparent option, candidates compared (one line each: name, strength, weakness), selection and why it beat the runner-up;
- the identity unit: the truth it expresses, the personality device, the construction family chosen against the other candidates, the runner-up, how mark and wordmark are integrated, and the distinction mechanisms used (or "fixed asset");
- any supporter or system decision that had real alternatives.

Update the Design Log: color, type, mark and lockup, element costs, open issues.

**Hand-off to Phase 5:** the element system with every element's role, treatment, relationships, effect profile, and space cost; the identity unit with its mechanisms; the constraints that the prompt must preserve.
