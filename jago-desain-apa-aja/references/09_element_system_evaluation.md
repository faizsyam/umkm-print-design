## 2. Guidance (continued from `08_containers_and_ground.md`)

### F. System review (once)

Judge the system and its additions in relation to the whole, as one read:
- **Realization.** Each addition (supporter, decoration, counterweight, designed container) carries a purpose line naming the plan commitment it realizes; an addition realizing none is removed, and a commitment realized by nothing is a gap. Every quality requirement has a visible carrier.
- **Allowance and load.** Space costs are classes (small, medium, large against the structure-and-decoration line), never dimensions; the total fits that line with the quiet intact, and no category dominates the load tally without being the hero or the information. If over, remove or merge additions before shrinking any, lowest rank first.
- **Removal and distinctness.** An addition whose loss costs nothing the piece needs is removed unless a second purpose earns it; each must beat its next-lighter alternative (nothing, spacing, a rule, a smaller form); two additions with one function merge.
- **Weight and plane.** At each stage no decoration outranks the required information it serves, a forward plane's prominence included; each element sits on one plane and its cues agree.
- **Single voice.** Line quality, finish, abstraction level, light direction, and rendering treatment read as one designer's work; every rendering treatment is in the Phase 3 vocabulary and applied uniformly by role.
- **Additive and subtraction.** Re-read the text-only baseline: close each real gap by the order of remedy (`07_visual_supporters_and_figures.md` D), never filler; where the system stays plain, the plainness is a named decision backed by the character test; would removing one more thing improve the piece?
- **Connection and character.** Every major element links to at least one other; with the name covered, at least two ownable character carriers from different levers remain, carried first inside elements the system already needs.
