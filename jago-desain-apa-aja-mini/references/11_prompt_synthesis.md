# Phase 6: prompt synthesis and prompt audit

**Needs:** S (set, mandatory strings verbatim, fixed assets, exclusions, qualities with carriers, generator/language if named); each deliverable's Execution Specification and the Phase 4 specifications it names; Phase 3 style dimensions and hero specifics. **Not received:** records, candidates, research, tensions, rationale, purpose lines (the Specification carries their consequences). **Exploration:** none: synthesis is translation, not invention. If translation needs a new concept, style, or element, an earlier phase had a gap: return and re-run forward.
**Process:** confirm the Phase 5 gate and Ready-for-Phase-6 passed → fix the prompt set (§F) and sort every element in or out (§A) → assemble each prompt separately from the Specifications (Execution decisions such as line breaks, non-mandatory wording, small item and icon details are made here, directly) → structure (§B), clauses (§D-E), specificity (§C) → length, static artwork, exclusions, ratio (§F) → audit (§G) → label, usage steps, notes (`12_user_messages.md`).

## A. In and out
**Out:** strategy, brand story, audience/environment analysis, research, the piece's purpose, success criteria, alternatives, any "because" or "in order to". They acted through decisions; the prompt carries the visible traits they produced. An impression word may stay only as a brief tone anchor that steers rendering.
**In:** piece type and format (orientation, ratio, sides) and nothing about purpose (purpose goes in the label); the overall look as seen, stated once as the unified art direction (value key and dominant field, mood, light, surface and finish, depth cues, how treatments step down by rank, the illustration language as visible traits: lineage and borrowed traits, how shapes are built, line behavior, how form is rendered, surface and detail steps); what is depicted and how; composition and relationships, hierarchy as first/second/third with the visible means each holds, the reading route over described regions; typography per role and designed copy; mandatory text; supporters and decoration as concrete forms; color and surface; mark construction; ground and unifying devices; the few finishing details that matter; rendering technique; necessary exclusions. Express size as ratios between elements; state emphasis only where the Specification holds it, never as blanket emphasis words.

## B. Structure
Order by consequence: (1) piece and format; (2) overall look (value key and dominant field first, so qualities govern generation); (3) spatial composition (density, quiet regions, atmosphere fields, separation), then hierarchy; (4) hero and main visuals; (5) identity unit; (6) typography; (7) color; (8) ground and unifying devices; (9) supporting details; (10) mandatory text in context. Adapt to complexity; one style logic from first sentence to last. Generators weight early content most, so the opening carries format, look, value key, hero composition, and hierarchy.

## C. Specificity
- Precise design vocabulary and concrete description; a sentence an illustrator could read two ways is not yet specific.
- Describe each depicted thing by its true specifics (form, material, construction, arrangement) from Phases 3-4, not by category name, which summons the model's apparent instance.
- State every look-shaping attribute the plan decided; an unstated one takes the apparent value. If no phase decided it, return to the owner rather than invent it. Silence only where that value is the intended result.
- Illustration, photography, mixed media by their decided language (never the medium's name).
- Color by hue with qualifiers, role, and intensity: which is the large calm field, which is the sparing accent and where, so the generator does not distribute saturation by area.
- Rendering treatments only as the vocabulary names them, by role; where the style has none, state flat plain rendering positively.

## D. Relationships, space, balance
**Relationships.** State the hierarchy (few ranks, each with its means) and the route over described regions, agreeing with placement: an element read first or second sits where the route puts it, and no ordering word contradicts a position word. Describe relative prominence, grouping, contrast, integration, plane order (rearmost to front), how identity, message, supporters interact. Position by relationship and broad region, never coordinates. Neighbors in relational words: alignment to an edge or axis, gap size, beneath, beside, in front of, clear ground. An overlap names the front element and the visible part of the covered one. Compose as relationships among hero, groups, and ground; partition words (zone, section, block, panel, band, column) only where the design contains that physical form.
**Space** (models fill space unless told). State it as the layout's own structure, positively, before element detail:
- outer margin, separation between groups, isolation around hero and unit, each container's inner padding as a relation to its text (about one line-height; its height follows content, so text is neither squeezed nor enlarged; a stated height only as a designed proportion never beside text sizes and counts that leave less), the open regions by what they separate or frame and roughly how much of the format they hold, overall density in plain words;
- text sizes as ratios between tiers and relative to neighbors; shares of the format only for major regions (§F); enlarge no element to fill room; add no decoration beyond the decided supporters, atmosphere, counterweights;
- the quantity of every repeated or decorative form as decided (so the generator neither multiplies forms nor fills the quiet); richness the plan decided is as concrete as restraint, never at the smallest safe count when the stance wants a developed world; name absences only where the generator would add them;
- atmosphere fields apart from quiet regions (which stay plain): motif, scale, contrast, where, how they recede under information;
- agreement between space and element clauses: no clause says an element fills, spans, covers, or packs its zone; long lists grouped into few zones with the arrangement described once (a long description signals importance and density).
**Balance:** state the relation as built (which side carries the mass, which quiet carrier answers) as concrete forms and regions.

## E. Text, marks, assets
- **Mandatory text:** verbatim in quotes, once, tied to position and role. Dense text grouped in reading order, row behavior described once. Prices and contacts get clarity proportionate to their stage. Say the piece contains only the specified text when hallucinated text is a risk. Never omit mandatory text to shorten; flag volume risk in notes.
- **Look clause:** the style's visual language, technique, light as drawable traits, stated once and applied by name to every element: lineage (never a living artist, studio, protected character) and traits borrowed; how shapes are built and proportioned; line behavior (weight, variation, ends/corners, closure); how form is rendered (flat steps, one shade, hatching, brush or cut-paper edges, overprint) and where it stops; surface and print character (tooth, grain, registration, ink) and where it lives; detail steps by rank; color treatment. Strike category/medium words and bare mood adjectives: what remains must still tell an illustrator how to draw it. Mascot, objects, lettering, supporters, ground share this logic; texture stays in assigned zones.
- **Hero group:** one composition: the hero first; each integrated item with the exact part it points to, side or path, pointer style (form, weight, terminal, end part); attached items by position; the relationship in one sentence. Arched text is one short line on one smooth curve. Overlapping elements name the front element and the visible covered part.
- **Type per role:** the distinguishing contrast of each role once; each role's letterform proportions and baseline (natural, upright, level unless decided), letter- and line-spacing, case, alignment; text regions with room to spare so the generator never compresses or tilts letters; equivalent items stated once as sharing size, weight, style whatever their length (cards/rows: identical outer size, internal layout, field positions, longer text wrapping to an extra line, never shrinking); a multi-line string's planned wrap, the verbatim text split only at those breaks.
- **Designed copy:** letterform, breaks, emphasis, container, color role, position; a quality adjective is not a description.
- **Supporters:** concrete forms (what, how drawn, where, how large against neighbors, what color), never a category word, each below the weight of adjacent information; where a symbol carries an item's kind, the text beside it is the data alone.
- **Containers and shapes:** each one's job, form, corner/edge geometry, material impression, edge ornament, fill, layering; the shape language stated once and applied by name; no-container groups stated as open grouping held by spacing and alignment; never leave containers unstated (they take the default rounded form); describe per information role.
- **Grounds and edges:** texture or pattern = low-contrast surface beneath content, only in assigned zones, calmer under denser text, never in the plain quiet regions; scrim = translucent tonal layer behind the named text zone; bleed = an element running off the trim while text stays inside the margin; a decided surface described concretely, a uniform ground stated as uniform. **Planes:** relational order rearmost to front with cue; for any overlap, front element and the covered part left visible; mandatory text keeps every letterform whole, and say so.
- **Supplied logo/character:** by reference if the model accepts images, else described faithfully, never replaced by an invention. **Reserved asset panel:** position, share, flat color, frame, isolation, nothing inside. **Figure:** form class and construction, proportions, silhouette, signature trait, expression and posture, rendering, palette, pose and relation to the offer; fictional; identical wording everywhere.
- **New mark:** form class, geometry, silhouette, color, boundary, device, relation to the wordmark, separation from adjacent type, concrete enough to be drawn the same way each time; state the name's exact letters, every letter whole and in order. **Identity unit:** one object: arrangement, shared construction logic, proportion and spacing, axis, color roles, clear space and region.

## F. Length, numbers, artwork, exclusions, ratio, language
- **Numbers:** no pixel or millimeter measurements, coordinates, or exact angles. Sizes are ratios between tiers ("about one and a half times the item-name height") and shares for the major regions only (hero group, main information group, footer, margin): about six numbers per prompt at most, since percentages dilute the decisions that matter. Stated sizes come from the floors and region table, never remembered conventions.
- **Length** is proportional to complexity; every sentence carries a decision or relationship; describe each element in proportion to its rank and give open regions the same specificity as elements. Cut filler before specifics; restore specifics before adding length.
- **Static artwork:** finished flat artwork unless a mockup is requested or the physical form is the deliverable; no crop marks, bleed guides, annotations unless requested.
- **Exclusions:** express traits positively; exclude only for explicit user exclusions, high-probability failures that matter, cultural or factual risks. An exclusion never substitutes for a decision.
- **Ratio:** state the deliverable's ratio from S in the opening line; describe the full design at that ratio; no substitute, crop, or note.
- **One prompt per deliverable (per concept)**; never split one image's content or merge deliverables needing different compositions. Each prompt is **complete alone**: names its piece and format, restates shared decisions (identity, style, color, type, supporters, figure) in identical words, carries its own composition, hierarchy, text; never refers to another prompt, an earlier generation, the brief, or a series. **Language:** English by default with on-image text verbatim, unless the user asks otherwise or names a model that does better in another language; everything outside the prompt in the user's language; each prompt alone in its code block.

## G. Prompt audit (the Phase 6 gate; runs on every prompt, then the set)
- **Plan fidelity:** every Execution Specification decision present; nothing new; every shown or amended decision visible and none contradicted.
- **Mandatory content:** every string present, verbatim, once, with role and position; suspected typos preserved and flagged.
- **Fixed assets:** reproduced as provided. **Exclusions** respected; only minimal specific ones added; no invented facts; no competitor copying.
- **Identifier:** not merely a styled name unless supplied or requested; new mark described by form class, geometry, silhouette, color, boundary, device, wordmark relation, separation; unit as one object; exact letters stated and whole.
- **Order and roles:** ranks stated and the route agrees with every position clause; type roles distinguished; overlaps name front element and visible covered part.
- **Containers and balance:** each container states form, corner/edge geometry, material impression, layering, fill (or open grouping); any counterweight a concrete form and region; none relies on a default.
- **Space:** open regions named by what they separate or frame with rough share and plain-word density, before element detail and consistent with every clause; margin, separation, isolation, internal spacing, resting fields as positive features; each group and container carries its share of the governing dimension, text roles their ratios to one another; quiet described as plain and atmosphere apart; every repeated form's quantity stated; equivalent units identical; each zone's own breathing room stated; for the densest container, text sizes, line counts, padding, width, height consistent; the ratio from S unchanged.
- **Qualities:** each shows in the opening lines through named features; value key stated; nothing contradicts a quality.
- **Copy and supporters:** described by traits and forms, matching the shown decisions, none outweighing required text; no symbol repeats adjacent words.
- **Visual-effect and misread tests on every sentence:** would removing it change what is drawn (if not, delete)? What is its likeliest wrong rendering (if that breaks the design, rewrite until the likeliest reading is the intended)?
- **Standalone:** complete alone; prompt count matches the set.
- **Specifics:** depicted things by true specifics in the decided language; strike test passes.
- **Hygiene:** no rationale, no partition words without that form, no placeholders or blank zones (except a reserved asset panel), no post-generation editing instructions, no blanket emphasis, no crop marks, one style logic.
